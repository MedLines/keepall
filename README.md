# Keepall

A local-first personal library for links and notes. Use it in the browser with no account.

## Development

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000). Press Alt+K or ⌥K to save a link or note.

## Commands

| Command | Description |
| --- | --- |
| `pnpm dev` | Start the development server |
| `pnpm lint` | Lint |
| `pnpm typecheck` | Type-check |
| `pnpm test` | Run unit tests |
| `pnpm test:watch` | Run unit tests in watch mode |
| `pnpm test:e2e` | Production build, then Playwright |
| `pnpm build` | Create a production build |
